# 基线评估报告剖面（EVAL）

本文件是 EVAL 正文结构的**自包含说明**。写 EVAL 时读本页与 [eval.md](../assets/templates/eval.md) 即可，**MUST NOT** 再检索外部标准条文来「对齐条款号」。

**渊源（仅溯源，非符合性目标）**：结构裁剪自软件质量评价常见实践，信息项思路参考过 ISO/IEC 25040（评价过程）、ISO/IEC 25010（使用情境）、ISO/IEC/IEEE 15289（评价报告类信息项）。**本 skill 不以这些标准的符合性为交付目标**；需要正式合规举证时，在项目 `ued/` 用 **REF** 登记购入标准，勿把标准全文塞进本技能包。

与 ADR / REF / TC / MET 的分界、元信息字段见 [type-profiles.md · EVAL](type-profiles.md#eval-与-adr--ref--tc--met)。

---

## 评价过程（本技能口径）

内部评价按四段推进；一篇 EVAL 是其中「规定 → 执行 → 结束」的**报告载体**，不是过程管理系统。

| 阶段 | 要回答的问题 | 主要落在 EVAL 的 |
|------|--------------|------------------|
| 建立评价需求 | 为何评、结果给谁用、评到什么算够 | `评价目的`、`评价对象与范围`、`使用情境` |
| 规定评价 | 用哪些尺子、怎样算通过/观察/不通过 | `评价指标与判定准则`、`评价方法` |
| 执行评价 | 测到了什么（相对准则） | `评价结果`；解释放 `结果分析` |
| 结束评价 | 总判、建议、可信度边界、是否再评 | `局限与假设`、`结论与建议`；开篇 `摘要` 供忙人决策 |

---

## 使用情境（本技能口径）

评价结论只在既定情境下成立。**使用情境** = 谁在什么条件下、面对什么外部运行条件做评价，本技能拆成两块：

| 子节 | 写什么 |
|------|--------|
| **运行环境** | 形态（实盘/模拟/回放）、标的与账户、设备与设施、配置相对 `对照版本`、与生产差异 |
| **运行场景（操作剖面）** | 可指认的外部条件窗：行情事件、故障窗口、稳态抽样等；先列场景再报数 |

操作/交易类评估：事件时间线与纳入/排除理由写在「运行场景」，**MUST NOT** 另起「背景与动机」「场景与事件」等平行 H2。

## 正文小节（MANDATORY 结构）

模板骨架见 [eval.md](../assets/templates/eval.md)。**MUST NOT** 另造与下表平行的栏目名。

| 小节 | 出现 | 写什么 |
|------|------|--------|
| `摘要` | MUST | 目的一句、情境要点、相对 `对照版本` 的总判、建议动作、最大局限；忙人只读本节应能决定是否深读或是否解冻设计 |
| `评价目的` | MUST | **结果用途**（结论用于何种决策）；**触发与必要性**（为何现在评；与基线/上一篇 EVAL 的关系）；**成败动作**（通过/观察/不通过时各自下一步） |
| `评价对象与范围` | MUST | 评价对象（可链 MET/NFR/ALG/TC/FR）；纳入；排除（非目标，至少一条）；可选评价严格程度（抽查/关键场景/全面） |
| `使用情境` | MUST | 上节「运行环境」+「运行场景」；先情境后度量 |
| `评价指标与判定准则` | MUST | 先定尺子再报数：指标定义与采集口径、通过/观察/不通过界限；可选关联 MET/NFR |
| `评价方法` | MUST | 方法、数据、复现、假设、与 `对照版本` 下哪组行为对应 |
| `评价结果` | MUST | 可核对观测值与对照；避免无对照定性套话；可按运行场景拆分（可选） |
| `结果分析` | SHOULD | 归因、异常、稳健性；事实与推断分开；证据不足时不要提前下设计变更结论 |
| `局限与假设` | MUST | 样本偏差、过拟合、前视、成本模型、未覆盖场景、实盘差异；写明**不得据此推出的结论**；若建议解冻设计须说明证据强度 |
| `结论与建议` | MUST | 总判；对运维；对设计（建议解冻的编码）；后续评价条件 |
| `附录` | MAY | 原始产物路径等；无则删节 |

## 内容归位

| 意图 | 写入 |
|------|------|
| 为何现在评 / 动机 | `评价目的` · 触发与必要性（不是独立 H2） |
| 大跌、故障窗等事件梳理 | `使用情境` · 运行场景 |
| 实盘/回放、账户、设施 | `使用情境` · 运行环境 |
| 尺子与阈值 | `评价指标与判定准则`（先于结果） |
| 数与判定 | `评价结果`；解释在 `结果分析` |
| 「不能外推什么」 | `局限与假设` |
