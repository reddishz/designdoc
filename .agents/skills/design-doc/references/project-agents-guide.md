# 项目接入：根 AGENTS.md 托管块与宿主适配

design-doc 面向所有支持 skill 的宿主（Cursor、Codex、Claude Code、Qoder 等），不绑定任何一个。技能靠宿主按 `description` 判断是否加载，**不保证每次都触发**；Agent 读过规则也可能在执行顺序上违规。因此接入要落下**常驻入口**：宿主每次会话都会读到的指令。

常驻入口分两层：

| 层 | 内容 | 是否与宿主无关 |
|----|------|----------------|
| **核心：根 `AGENTS.md` 托管块** | 声明采用 design-doc，写明硬性顺序与 Gate 入口 | 是。`AGENTS.md` 是跨宿主约定，检查器只读它 |
| **宿主适配** | 把常驻入口接到具体宿主的指令机制上（如 Cursor 的 always-apply 规则） | 否。按宿主选择，见下文「宿主适配」 |

两者都**不复制规则正文**，细则永远在技能包里。它们只是入口，**不能保证**行为；接入是否成功要靠冒烟验证。

## 接入检查清单

接入（或「检查接入」）按下列顺序逐项确认，缺哪项补哪项。每次写入前都要向用户说明内容并取得确认：

1. 确认项目采用 design-doc：存在设计目录（默认 `ued/`），或用户明确要采用但尚未建立。
2. 确认技能已安装：技能目录下有 `SKILL.md`（本项目安装于 `.agents/skills/design-doc/`）。
3. 根 `AGENTS.md` 含托管块，块号与正文与已装技能一致（见下文「写入规则」）。
4. 宿主适配：按用户使用的宿主，确认其常驻入口已接上（见「宿主适配」）。未启用的宿主不必检查。
5. 有旧式章节（上一版指南生成的「设计文档优先」）则迁移，见「旧式章节迁移」。
6. 填好块外占位（见「块外内容」）。
7. 运行检查器（不带设计目录时也可运行）：`python3 .agents/skills/design-doc/scripts/check_docs.py -p <设计目录>`；使用 Cursor 时加 `--host cursor`。AGENTS 相关问题全部消除。
8. 通过[冒烟验证](#冒烟验证)。

**接入完成的标准是通过冒烟验证，不是文件生成完成。**

## 托管块

块源文件：[assets/snippets/agents-block.md](../assets/snippets/agents-block.md)。整块原样写入项目 `AGENTS.md`，标记独占一行：

```text
<!-- design-doc:begin block=N -->
...
<!-- design-doc:end -->
```

### 块号 `block=N` 的用途

`block=N` 是**托管块的内容修订号**，块正文每次变化都递增，与设计文档修订号、规范版本、产品版本都无关。它的作用：

- **判断副本是否过时。** 项目 `AGENTS.md` 里的块是技能块源的副本。技能升级后，检查器比较两边的块号：副本较小报「托管块落后」，较大报「超前」（技能被回退或版本不一致）。
- **识别手改与漏改。** 检查器同时比对块正文：块号相同但正文不同，说明副本被手改，或技能块改了却忘了递增块号。两种情况都报「正文不一致」。
- **把更新变成需确认的动作。** 块不会自动同步，块号落后就是提示用户确认后整块替换的信号。

历史：`block=1` 初版；`block=2` 补充 `ued/` 不变量与校验命令；`block=3` 增加 M 判定与 Gate 时序；`block=4` 精简为 6 条约束。

因此块正文只能整块替换，**不得在块内加项目个性化内容**；改块正文时必须同步递增块号。

### 篇幅目标

- 通用规则 **5～7 条**，检查器上限为 7 条（「托管块规则过多」）。
- 每条只表达一个约束。
- 不复制 workflow 的具体步骤，不复制状态、字段和审批规则。
- 项目特有信息（编码、设计目录、多子系统路由、产品版本）放在托管块之外。

三者分工：`AGENTS.md` 是路标，Skill 是操作手册，workflow 是具体作业流程。

## 写入规则

- **AGENTS.md 是用户文件。** 首次写入或更新前，**MUST** 向用户说明将写入的内容并取得确认。
- **无 `AGENTS.md`**：新建，写一个 H1，再写入整块。
- **已有 `AGENTS.md` 无块**：在末尾追加整块；**MUST NOT** 改块外内容（旧式章节见下节）。
- **已有块，块号落后或正文不一致**：只替换起止标记之间（含标记）的整块，块外内容原样保留。
- **宿主适配文件**：见「宿主适配」，写入前同样须确认。

## 旧式章节迁移

上一版指南生成的 `AGENTS.md` 常含一节未带标记的「设计文档优先（有 ued/ 时 MUST）」。它与托管块并存会出现两套规则。检查器报「AGENTS.md 含旧式设计优先章节」时：

1. 向用户列出该节原文，说明将删除并由托管块替代。
2. 用户确认后，删除该节，并把托管块放在它原来的位置（或文件末尾）。
3. 其余块外内容不动。

## 宿主适配

核心入口是托管块。下表列出各宿主如何把它接成常驻入口。**只有 Cursor 一行给出了具体机制**，且本项目只验证了其文件格式，未验证注入行为；其他宿主需在接入时对照该宿主的官方文档核实，核实前不得假定其行为。

| 宿主 | 常驻入口 | 检查器 | 验证状态 |
|------|----------|--------|----------|
| 通用（所有宿主） | 根 `AGENTS.md` 托管块 | 默认检查 | 检查器与宿主无关；注入行为未冒烟 |
| Cursor | `.cursor/rules/design-doc-bootstrap.mdc`，`alwaysApply: true`，源文件 [assets/snippets/design-doc-bootstrap.mdc](../assets/snippets/design-doc-bootstrap.mdc) | `--host cursor` | 文件格式可检；每次会话是否注入未冒烟 |
| Codex / Claude Code / Qoder / 其他 | 待核实：各宿主的常驻指令文件（如 `CLAUDE.md`）中一句指向根 `AGENTS.md` 的引用 | 暂无 | **未核实**：需对照该宿主文档确认是否读取 `AGENTS.md`、指令文件位置与格式 |

规则：

- **不要**在宿主适配文件中复制托管块正文，只写引用或指向。
- 宿主适配文件是**可选**的：宿主本身已读 `AGENTS.md` 时，不需要额外文件。
- 检查器只检查用 `--host` 启用的宿主。新增宿主时，在本表增加一行，并在 `check_docs.py` 增加对应的 `--host` 选项，**不得**把宿主专用逻辑放进默认检查。

### Cursor 规则文件的格式要求

由 `--host cursor` 检查，合格须同时满足：

- frontmatter 首行为 `---`，到下一个 `---` 闭合；
- `alwaysApply` 为布尔值 `true`（注释中的同名字符串不算）；
- 正文指向根 `AGENTS.md`，并提到「编码前设计 Gate」。

## 块外内容

块外是项目自己的地方，写入项目特有信息，不要写进块：

- 项目编码（来自 `ued/README.md` 项目元信息）；
- 设计目录路径，若不是默认 `ued/`；
- 当前产品版本（来自 `ued/README.md` 的 `产品版本`）；
- 项目其他约定（构建、测试、提交规范等，与 design-doc 无关的内容）。

## 多子系统变体

系统根的 `ued/README.md` 含子系统注册表时，仍只在**项目根**放一份 `AGENTS.md` 和一份托管块。托管块第 7 条已说明路由，块外可补充子系统清单。

若仓库里存在多个带托管块的 `AGENTS.md`（如仓库根与子项目各一份），检查器报「存在多个带托管块的 AGENTS.md」。请保留唯一的项目根入口，其余删除托管块，或改用唯一的根。

## 冒烟验证

给 Agent 一条典型请求，例如「把某功能的行为改成……」或「修一下某个缺陷」，期望的第一步是：

- Gate 记录是本轮第一个输出，包含已读文件、设计依据、基线、状态与判定；
- 判定为 B、C、D 时**本回合到此结束**，没有调用编辑工具，也没有修改文件；判定为 M 或 A 时才可继续。

失败时按顺序排查：`AGENTS.md` 是否在项目根且被宿主加载；宿主适配文件（如启用）是否就位；技能路径是否可发现；块是否完整。修好后重测。

冒烟验证是对话行为的人工验收，无法脚本化。检查器只能证明块存在、块与已装版本一致、宿主适配文件格式合格。

## 检查器报告

`check_docs.py` 在项目根查找 `AGENTS.md`。项目根按位置推定：单系统为设计目录的上一级；子系统 `ued/{subsystem}/` 为 `ued/` 的上一级；仓库根（含 `.git` 或 `.svn` 的最近祖先）也被接受。宿主适配文件与所选 `AGENTS.md` 同根。无设计目录时仍检查。

| 问题名 | 级别 | 含义 | 启用条件 |
|--------|------|------|----------|
| 项目缺 AGENTS.md | WARNING | 项目根没有 `AGENTS.md` | 默认 |
| AGENTS.md 缺设计优先托管块 | WARNING | 有 `AGENTS.md` 但没有 design-doc 托管块 | 默认 |
| AGENTS.md 托管块不完整 | WARNING | 起止标记缺失、重复、顺序错，或 `block=N` 缺失 | 默认 |
| AGENTS.md 托管块落后 | WARNING | 块号低于已装技能；按本文整块更新（须确认） | 默认 |
| AGENTS.md 托管块正文不一致 | WARNING | 块号相同但正文不同；按本文整块替换（须确认） | 默认 |
| AGENTS.md 托管块超前 | ERROR | 块号高于已装技能；技能回退或版本不一致 | 默认 |
| AGENTS.md 含旧式设计优先章节 | WARNING | 块外残留未带标记的旧章节；按「旧式章节迁移」处理 | 默认 |
| 存在多个带托管块的 AGENTS.md | WARNING | 多个候选项目根都含托管块，须保留唯一入口 | 默认 |
| 缺 design-doc 常驻规则 | WARNING | Cursor 规则文件缺失或格式不合格 | `--host cursor` |

检查器不做语义检查：块外是否有与 design-doc 冲突的旧规则，只能靠人审。
