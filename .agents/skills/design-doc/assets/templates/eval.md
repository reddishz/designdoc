> **模板：EVAL - 基线评估报告**（相对产品基线的内部评价长文 / 证据槽；一事一档。切分见 [type-profiles.md · EVAL](../../references/type-profiles.md#eval-与-adr--ref--tc--met)；信息项角色见 [object-model.md · 信息项角色](../../references/object-model.md#信息项角色agent-选槽)。存 `L6-verification/`，不设 `eval/`。以下整段前置说明 **勿写入实例**。）
>
> **结构依据（裁剪自国际标准，非自造栏目）**：
>
> 1. **ISO/IEC 25040**（SQuaRE 质量评价过程）：建立评价需求 → 规定评价（度量与判定准则）→ 设计/执行 → 结束评价（结果评审、报告、反馈）
> 2. **ISO/IEC 25010**：**使用情境（context of use）**= 用户、任务、设备与环境；操作行为类评估把「在何种运行场景下表现」写进本节（含行情事件、故障窗口等操作剖面）
> 3. **ISO/IEC/IEEE 15289** Evaluation report 信息项：目的、范围、准则、方法、结果、结论与建议
>
> **通用规则**：见 [index.md · 整篇型模板共用](index.md#整篇型模板共用)。
>
> **本模板**
>
> 1. `对照版本` 钉所评基线；同一对照版本上可有多篇 EVAL
> 2. 触发原因（如近两次大跌）写入 **评价目的**；事件梳理与运行环境写入 **使用情境**——**MUST NOT** 另起非标准栏目名
> 3. 分配 `EVAL` 后更新 README 文档索引；《本文引用》在变更记录前
> 4. **MUST NOT** 当作实现门禁或写入 `baselines/items`；外部资料用 REF
>
> **正文边界**：见 [index.md · 模板边界（哨兵）](index.md#模板边界哨兵)。
