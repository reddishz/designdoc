> **模板：EVAL - 基线评估报告**
>
> **定位**：相对某产品基线的内部度量/评价长文（证据槽）；一事一档。切分见 [type-profiles.md · EVAL](../../references/type-profiles.md#eval-与-adr--ref--tc--met)；信息项角色见 [object-model.md · 信息项角色](../../references/object-model.md#信息项角色agent-选槽)。存放于 `L6-verification/`，不设 `eval/` 子目录。
>
> **通用规则**：见 [index.md · 整篇型模板共用](index.md#整篇型模板共用)。
>
> **本模板**
>
> 1. `对照版本` 钉所评基线（可与当前 README `产品版本` 不同）；同一对照版本上可有多篇 EVAL
> 2. 默认无细项清单；分配 `EVAL` 后更新作用域 README 文档索引。《本文引用》放在变更记录前（表体可空）
> 3. **MUST NOT** 当作实现门禁或塞进 `baselines/items`；外部资料用 REF，本模板只写内部评估
>
> **正文边界**：见 [index.md · 模板边界（哨兵）](index.md#模板边界哨兵)。
