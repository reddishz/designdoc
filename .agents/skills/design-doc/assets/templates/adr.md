## 本文档细项编码清单（仅列出本文档定义/包含）

> **清单范围**：仅收录**本文档**定义或包含的细项，**不是** `ued/` 下的全局完整清单。
> **分配流程**：分配编码前必须先检索当前作用域 `README.md` 的全局编码索引，确认无冲突后再分配；分配后同步更新该索引。
> **状态列**：`细项状态` 为必备列，新建默认 `初稿`；决策本身的文档状态见文首《状态》字段。

| 编码       | 类型     | 标题     | 细项状态 |
| ---------- | -------- | -------- | -------- |
| DEC-{编号} | 决策     | {标题}   | 初稿     |

## 变更记录

## 使用说明

1. 替换 `{编号}`、`{决策标题}` 等占位符
2. 状态值从 `初稿/正式/草案/废弃` 中选择；**新建默认 `初稿`**（缺字段时按 `变更记录` 判定：有定稿条目 → `草案`，从未定稿 → `初稿`，无法判定 → `草案`）。ADR **不设专属枚举**：原「采纳」= `正式`（已冻结基线），原「拒绝」= `废弃` + `废弃原因`，原「取代」= `废弃` + `替代方案`；`正式` 后的实质修订需先解冻为 `草案` 并**在解冻时递增版本号**（见 `references/status-definitions.md`）
3. **编码形式与项目前缀**：见文首说明
4. **本文档细项编码清单**：仅本文档范围；分配前检索当前作用域 `README.md` 全局索引，分配后同步更新
5. 关联文档引用对应的 L3 文档编码
6. 维护细项编码清单和变更记录
