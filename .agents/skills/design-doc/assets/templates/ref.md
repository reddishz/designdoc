# REF - 外部参考资料模板

## 类型一：纯外部链接

```markdown
# REF-{编号}-{资料名称}

| 属性       | 值                             |
| ---------- | ------------------------------ |
| 文档编码   | REF-{编号}                     |
| 类别       | REF - 外部参考资料             |
| 状态       | 初稿        |
| 录入人     | {当前用户.作者}                         |
| 录入日期   | YYYY-MM-DD                     |

> **编码形式**：默认使用简洁编码（`{类型码}-{三位序号}`，与正文占位符一致）。
> **项目前缀**：仅在当前作用域 `README.md` 已声明 `project_code` 且请求发起方明确确认启用时，在各类编码前加 `{项目编码}-` 前缀（细则见 `references/coding-system.md`）。

## 来源信息

> **时效字段属记录型**：`来源版本` / `获取日期` / `最近核验日期` / `复查周期` / `失效风险` **不参与冻结**；每次核验后更新 `最近核验日期` **不解冻、不递增版本号**（见 `references/status-definitions.md#记录型字段不参与冻结`）。

- **类型**：标准/论文/书籍/技术文档/竞品资料/网页/其他
- **来源**：{出处，如组织名称、网站、出版社}
- **链接**：{URL，可以是多个链接}
- **来源版本**：{版本号 / 版次，如适用}
- **获取日期**：YYYY-MM-DD
- **最近核验日期**：YYYY-MM-DD
- **复查周期**：{如 6 个月 / 1 年}
- **失效风险**：{低 / 中 / 高，及说明}

用一到两段话概括该资料的核心内容和关键结论。

```

## 使用说明

1. **类型一（外部链接）**：只保留来源信息和摘要
2. **类型二（本地文档）**：头部 + 来源信息 + 原文档内容
3. 状态值从 `初稿/正式/草案/废弃` 中选择；**新建默认 `初稿`**（缺字段时按 `变更记录` 判定：有定稿条目 → `草案`，从未定稿 → `初稿`，无法判定 → `草案`）。REF **不设专属枚举**：原「登记中」= `初稿`，原「有效」= `正式`（已冻结基线）；`正式` 后的实质修订需先解冻为 `草案` 并**在解冻时递增版本号**（见 `references/status-definitions.md`）
4. **时效字段**（记录型，不参与冻结、不解冻不变号）：`来源版本` / `获取日期` / `最近核验日期` / `复查周期` / `失效风险` MUST 齐备；每次核验后更新 `最近核验日期`，超过 `复查周期` 未核验将被审核与 `check_docs.py` 判为「REF 需复核」
5. **编码形式与项目前缀**：见类型一/类型二文首说明
6. **分配编码**：新增 `REF` 前检索当前作用域 `README.md` 全局索引，分配后同步更新（无独立「细项清单」小节时亦同）
