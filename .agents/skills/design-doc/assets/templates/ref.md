> **模板：REF - 外部参考资料**
>
> **通用规则**：见 [index.md · 整篇型模板共用](index.md#整篇型模板共用)。
>
> **本模板**
>
> 1. 类型一：来源信息 + 摘要；类型二：头部 + 来源信息 + 原文档内容。按需取对应哨兵段
> 2. 无细项清单小节；分配 `REF` 后只更新作用域 README 全局索引
>
> **正文边界**：见 [index.md · 模板边界（哨兵）](index.md#模板边界哨兵)。
